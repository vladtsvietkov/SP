# DewWindow: PRD v1
Цвєтков Владислав Олександрович, ІО-32.
Продукт оцінює ризик конденсації на холодній поверхні: DHT22 дає T/RH повітря,
NTC вимірює поверхню, BMP180 дає тиск для вологовмісту. Для мешканця це спосіб
відстежувати холодні віконні ділянки й тривалість небезпечних умов.
Він не вимірює самі краплі та не керує опаленням.

[Функціональні вимоги FR01–10, числові критерії й приймання](requirements.md) є частиною цього PRD.
[Компоненти](hardware-components.md), [архітектура](architecture.md),
[майбутні експерименти ЛР3–4](future-experiments.md).

Модель майбутнього продукту: VALID/DEGRADED; DRY/APPROACH/RISK, підтверджене
відновлення через 5 с. Формат епізоду v1: id, start_ms, duration_ms,
max_deficit_centiC, validity, interrupted, sequence, CRC32.
У ЛР2 перевіряється сенсорна підсистема і математичне ядро. Повний журнал,
епізоди та командний інтерфейс реалізуються у ЛР3; baseline ще не виміряна.
